# Finly.Shared.Contracts

This package contains shared data contracts used across Finly microservices.

## Features

- Common DTOs and interfaces
- Lightweight and portable
- Targeting .NET 8.0

## Usage

Install the package from GitHub Packages:

dotnet add package Finly.Shared.Contracts --source "https://nuget.pkg.github.com/Finly-app/index.json"
